Typing Guide / टाइपिंग गाइड

Home Row Finger Placement

Essential Rules

🏠 Return to home row after each key

🙈 Never look at keyboard

👆 Use correct finger for each key

⚡ Press keys gently

☕ Take breaks every 30 minutes

💡 Consistency is key to building muscle memory

Practice Tips

Daily Practice: 15-30 minutes daily

Morning: Best time for learning

Warm Up: Start simple, end with challenge

Accuracy First: Aim for 95%+ before speed

Learning Path

Week 1-2: Home row (ASDF JKL;)

Week 3-4: Top row (QWERTYUIOP)

Week 5-6: Bottom row (ZXCVBNM)

Week 7-12: Words, sentences, paragraphs

💡 Track progress and celebrate milestones

WPM & Accuracy

WPM: Words Per Minute (1 word = 5 characters)

Accuracy: (Correct ÷ Total) × 100%

Speed Benchmarks

Beginner: 20-30 WPM

Average: 40-50 WPM

Good: 60-70 WPM

Professional: 75-90 WPM

Expert: 100+ WPM

💡 Focus on accuracy first, speed follows

Special Characters & Symbols

Special characters are typed using Shift + a number/symbol key. The finger guide below the keyboard will show you exactly which key to press during practice!

Shift + Number Keys

  • ! — Shift + 1 (Exclamation)
  • @ — Shift + 2 (At sign)
  • # — Shift + 3 (Hash)
  • $ — Shift + 4 (Dollar)
  • % — Shift + 5 (Percent)
  • ^ — Shift + 6 (Caret)
  • & — Shift + 7 (Ampersand)
  • * — Shift + 8 (Asterisk)
  • ( — Shift + 9 (Open paren)
  • ) — Shift + 0 (Close paren)
  • _ — Shift + - (Underscore)
  • + — Shift + = (Plus)

Shift + Symbol Keys

  • { — Shift + [ (Open brace)
  • } — Shift + ] (Close brace)
  • | — Shift + \ (Pipe)
  • : — Shift + ; (Colon)
  • " — Shift + ' (Double quote)
  • < — Shift + , (Less than)
  • > — Shift + . (Greater than)
  • ? — Shift + / (Question mark)
  • ~ — Shift + ` (Tilde)

Unicode Symbols (Alt Codes)

These special symbols require Alt + number code on NumPad. In practice, press the shown key instead. The finger guide will display the real Alt code for learning.

  • © — Alt + 0169 (Copyright)
  • ® — Alt + 0174 (Registered)
  • ™ — Alt + 0153 (Trademark)
  • ° — Alt + 0176 (Degree)
  • ± — Alt + 0177 (Plus-Minus)
  • × — Alt + 0215 (Multiply)
  • ÷ — Alt + 0247 (Divide)
  • • — Alt + 0149 (Bullet)
  • € — Alt + 0128 (Euro)
  • ₹ — Alt + 8377 (Indian Rupee)
  • § — Alt + 0167 (Section)
  • ¶ — Alt + 0182 (Paragraph)
  • ½ — Alt + 0189 (One Half)
  • ¼ — Alt + 0188 (One Quarter)
  • ¾ — Alt + 0190 (Three Quarters)
  • … — Alt + 0133 (Ellipsis)
💡 During typing practice, watch the finger guide bar — it shows the real Alt code for learning AND the practice key to press for each symbol!

Health & Tips

🪑 Posture

  • Feet flat, knees 90°
  • Monitor at eye level
  • Wrists straight

💚 Health

  • Break every 20-30 min
  • Stretch hands
  • Stop if in pain

🚀 Advanced

  • Practice symbols
  • Focus on accuracy

⚡ Tips

  • Practice daily
  • Don't look at keys

होम रो उंगली स्थिति

आवश्यक नियम

🏠 हर की के बाद होम रो पर वापस आएं

🙈 कभी कीबोर्ड को मत देखें

👆 हर की के लिए सही उंगली का उपयोग करें

⚡ कीज को हल्के से दबाएं

☕ हर 30 मिनट में ब्रेक लें

💡 निरंतरता मांसपेशी स्मृति बनाने की कुंजी है

अभ्यास टिप्स

दैनिक अभ्यास: रोजाना 15-30 मिनट

सुबह: सीखने का सबसे अच्छा समय

वार्म अप: सरल से शुरू, चुनौती के साथ समाप्त

सटीकता पहले: 95%+ का लक्ष्य रखें

सीखने का मार्ग

सप्ताह 1-2: होम रो (ASDF JKL;)

सप्ताह 3-4: टॉप रो (QWERTYUIOP)

सप्ताह 5-6: बॉटम रो (ZXCVBNM)

सप्ताह 7-12: शब्द, वाक्य, पैराग्राफ

💡 प्रगति ट्रैक करें और मील के पत्थर मनाएं

WPM और सटीकता

WPM: शब्द प्रति मिनट (1 शब्द = 5 अक्षर)

सटीकता: (सही ÷ कुल) × 100%

गति बेंचमार्क

शुरुआती: 20-30 WPM

औसत: 40-50 WPM

अच्छा: 60-70 WPM

पेशेवर: 75-90 WPM

विशेषज्ञ: 100+ WPM

💡 सटीकता पहले, गति बाद में

हिंदी संयुक्त अक्षर और विशेष वर्ण

कृति देव 010 में कुछ विशेष अक्षर अलग-अलग keys के combination से बनते हैं। ये अभ्यास के लिए महत्वपूर्ण हैं।

संयुक्त अक्षर (Conjuncts)

  • प्र — p + z (प + ्र)
  • हर्ष — h + Shift+z (ह + र्)
  • क्ष — Shift + [ (क्ष)
  • ज्ञ — Shift + k (ज्ञ)
  • श्र — Shift + j (श्र)
  • द्ध — Shift + 9 (द्ध)
  • द्व — Shift + ] (द्व)
  • द्य — Shift + \ (द्य)
  • त्र — = (त्र)
  • ऋ — Shift + - (ऋ)
  • श्‍ — ' (श्‍)
  • ष्‍ — Shift + " (ष्‍)
  • ध्‍ — / (ध्‍)
  • घ्‍ — Shift + / (घ्‍)
  • ण्‍ — . (ण्‍)
  • रु — Shift + 3 (रु)
  • रू — Shift + ; (रू)
  • ऑ — Shift + = (ऑ)
  • ँ — Shift + ` (ँ)
  • ॅ — Shift + w (ॅ)

कब उपयोग करें

  • प्र — प्रकार, प्रदेश, प्रश्न
  • क्ष — क्षत्रिय, मोक्ष, भाक्ष
  • श्र — श्रेष्ठ, श्री, श्रवण
  • ज्ञ — ज्ञान, संज्ञा, प्रज्ञा
  • त्र — त्रिकाल, पात्र, मित्र
  • हर्ष — हर्ष, विष्णु, वर्ष
